# v3 Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimal editorial personal site in `v3/` using Astro + MDX with writing, projects, and about pages, deployed to Vercel.

**Architecture:** Astro static site in the `v3/` folder. Content lives as `.mdx` files in `src/content/writing/`. All pages are Astro components using a shared `Base.astro` layout that injects meta tags, Google Fonts, View Transitions, and global CSS. No client-side JS except what Astro's View Transitions needs.

**Tech Stack:** Astro 4, MDX (`@astrojs/mdx`), Tailwind CSS v3 (`@astrojs/tailwind`), `@astrojs/sitemap`, Vercel adapter (`@astrojs/vercel/static`)

// v3/src/pages/writing/index.astro
import Base from '../../layouts/Base.astro';
import { getCollection } from 'astro:content';

const allPosts = await getCollection('writing', ({ data }) => !data.draft);
const posts = allPosts.sort((a, b) => b.data.date.valueOf() - a.data.date.valueOf());

function formatDate(date: Date) {
  return date.toLocaleDateString('en-US', { month: 'short', year: 'numeric' });
}

// Group by year
const byYear = posts.reduce<Record<string, typeof posts>>((acc, post) => {
  const year = post.data.date.getFullYear().toString();
  if (!acc[year]) acc[year] = [];
  acc[year].push(post);
  return acc;
}, {});

const years = Object.keys(byYear).sort((a, b) => Number(b) - Number(a));
---

<Base
  title="Writing"
  description="Essays and notes by Alan Wu on data science, engineering, and more."
  active="writing"

    {posts.length === 0 ? (

    ) : (
      years.map(year => (
        <div class="mb-10">
          <p class="text-sm text-muted mb-4">{year}</p>
